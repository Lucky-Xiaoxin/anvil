Data slots 数据槽位 · 界面上每个具体数字都是一个 data-bind

屏 1 的 markup 里每个值都挂着一个与接口字段同名的槽，渲染层只读 API 这一个对象；换成 fetch 的结果，组件一行都不用改。 取不到值的槽一律渲染 “—”，不渲染 0 —— 后端还没算这个数的时候，界面不会拿假数填空。

Decisions 最需要拍板的几件事

① 琥珀只干一件事：热 = 锻打发生过

琥珀同时是热力色阶顶端、主按钮、连续天数和顶栏余热线 —— 全部指向"你在这里花过时间"。数据蓝 --accent-2 单独承包一切数字与曲线，两色不混用，所以 rating 卡是蓝的、连续卡是琥珀的。若你认为 rating 才该是主角，就把两色分工对调。

② 连续天数走"诚实态"：12 天 + 今天还没开张

演示画像今天（10-03）没有 AC，主数字仍显示 12（从昨天倒推），副行明写"今天还没开张"，最后一格只留蓝色描边、不填色。宁可得罪人也不造假 streak。另一条路是今天没打就把数字转灰显示 0，更狠也更诚实，需要你定。

③ 周一开头 + 格子求和与生涯数不做强行对齐

按国内习惯周一为第一行（GitHub 是周日），行标签只留 一 / 三 / 五。格子求和 1024 题次、生涯去重 912 题 —— 两者没有加法关系（同题隔天再 AC 会在两个日格各亮一次），所以卡片脚注写的是口径而不是换算，免得日后被当 bug 提。

④ 密度换安静：一屏看完，不留欢迎语

1440×900 下 4 卡 + 格子图 + 曲线 + 2 张未解锁正好一屏不滚动；代价是 1280×800 开始纵向滚动，且没有留白给"今天也要加油"这类废话。格子图右侧那 3 行读数（最长连续 / 断档 / 周末占比）是同源派生，觉得多余可以整块删掉，不影响布局。

⑤ 未解锁用虚线卡，不用灰蒙层 / 锁弹窗

虚线 = "这里以后有东西，现在还没浇铸"，预告文案直接写切片号，给进度一个刻度。实心锁、打码模糊那套是商业产品付费墙的语气，本地自留地不该有。
