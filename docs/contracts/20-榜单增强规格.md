## 0. 一句话目标

目录里能把某一场的快照**预拉取**到本地（VP 前备好、断网可回放）；回放榜里能把**你 VP 的成绩**（逐发录入）作为一行「我的成绩」按引擎口径插进榜里——随时一眼看到自己排在哪两队之间、在什么奖区，顶栏读数点击可跳到那一行。

---

## 1. 预拉取（s1 目录）

**语义**：把单场 `srk.json`（~1.5MB）经服务端拉到 `vault/arena/` 缓存，**不进入回放**。已缓存 → 断网可回放（与 §2.1 缓存的既有降级承诺一致）。

**服务端**：
- `GET /api/arena/catalog` 的每个叶子加 `cached: boolean`（按镜像路径 `existsSync`；**新鲜路径与读缓存回吐路径都要标注**）；`ArenaCatalogNode`（shared）加可选字段 `cached?: boolean`。
- 预拉取本身**不新开接口**：前端直接调既有 `GET /api/arena/contest?path=`（命中即秒回；未命中走双源轮换 + 总预算，与回放取数同一路径）。

**前端（行内第三枚动作）**：
- 未缓存：`btn--xs btn--ghost` + sync 图标「预拉取」；点击 → 「拉取中…」（禁用重复点）→ 成功就地变「**本地**」小标（绿点）。失败 → 回到按钮 + 行内一行小字（复用现有失败口径，不弹大 alert；`.crow__err` 独占一行，行高自适应）。
- 已缓存：「本地」小标**替代**按钮；live 行（回放中）不显示（其动作是「回到回放」）。
- 与「开始模拟 / 查看终榜」并列常驻；三枚按钮在 1280 不折行。

**验收**：点击 → 三态过渡 → 刷新目录该行仍「本地」；上游断网时该场仍能从目录进入回放。

## 2. 幽灵行「我的成绩」（s2 / s3 榜体，v8 口径）

### 2.1 存储

- localStorage 每场一条 **`arena:ghost:<官方路径>`**：`{ show: boolean, subs: [{ p: 题序, t: 比赛分钟, r: 判名 }] }`。`r` ∈ 五档 **AC / WA / TLE / RE / CE**（照 CF 手输；**FB 不给选**——幽灵永不首杀；CE 不罚也不算失败发）。存时先按题、再按时刻升序。
- 坏 JSON / 读不懂 / 形状不对 → 当没有；**历史聚合形状（`{ show, marks:[{p,ac,fails}] }`）不迁移**，读出来当没有（面板全空重录）；非法逐发**整条丢弃**（判名白名单外、题序/时刻非非负整数）；缺 `show` 默认 `true`。读写一律 try/catch（同 `session.ts` 口径）。
- **清除本场成绩** = 删除该键；直接改数是覆盖，不需先清。幽灵**与 `vault/` 缓存、回放会话互不相干**。

### 2.2 引擎口径（核心，全部与榜单同源）

- `buildBoard(model, elapsed, onlyFormal, unsealed, ghost?)`，`ghost?: GhostSub[]`（`{p, t, r}`）。幽灵逐发**折算成 `SrkSolution` 交给真队同一条 `cellAt`**（每发都带时刻，复用同源口径比另造一套稳）——判名、封榜段 `?n`、CE 格、post 两态、**未过格的末次时刻**全部与真行同形。
- 计分（与榜单逐字同口径）：`solved = 已过题数`；`pen = Σ(AC 分钟 + 20 × AC 前失败次数)`。**AC 前失败计入罚时（×20）；未过题的失败不计**（ICPC 与全榜口径）。
- `elapsed`/`cap` 跟随现有引擎：live 段内只算 cap 前；回顾「封榜视角」**开** → 段内格回 `?n`；**关（默认解封）** → 显结果 + 「封榜后」两态。
- **名次与奖牌：占名额版** —— 走正式队通道：占 `place`、吃奖牌带，其下队伍名次与奖牌重排一位；`S#` **不给号**；**永不是 FB**（不抢首杀）。
- **排除项**：不计入榜脚「榜上 N 队 / 累计过题 M」、不计入列头「过 N / 交 M」与列头五档判定；封榜带「结果未知 N 格 · 涉及 N 队」**计入**。
- 平局沿用 `sameScore` + (last, ti)，幽灵以 `ti:-1` 排前，不另造规则。`ghostTeam` = 合成队伍（`你 / 我的成绩`、无成员、机位 `—`、`ti=-1`）供界面与弹层寻址（`ti === -1` 是暗号，**绝不查 `model.teams[-1]`**）。

### 2.3 界面（以 mock v8 为准）

- **入口（常驻）**：榜体顶栏（s2/s3 同一份）人形图标按钮（tooltip「我的成绩 · 录入 VP 成绩，看自己在榜上的位置」）。**不随数据出现/消失**——顶栏长相每场一致。
- **常驻读数**：顶栏「我 第 N 名」（绿点）——只在幽灵真在榜上时出现；tooltip 披露「x 题 / y 罚时 · 点击跳到榜上那一行」；点击滚到幽灵行并闪 1.1s（`is-jump`）；「展示我」关或一发未录时整块消失、不占位。
- **面板**：一行表单（选题 ▾ · 判名五档 ▾ · 时:分 输入（只收数字、自动补冒号、回车提交）· 提交）+ 校验（时间需 `时:分` / 不超本场时长 / **同一题第二个 AC 拒收**）+ **逐发清单**（每条单点删除）+ 「展示我」开关（默认开）+ 「清除本场成绩」（**两击确认**，3s / 失焦复位）+ 一行小注。
- **幽灵行（板内）**：左缘 accent 竖条 + 极淡 accent 底（可与奖牌底纹**叠加**）、ORG 列「我的成绩」、TEAM 列「你」（accent 色）；点格 / 点行弹层逐发化（段内那发显 `Frozen`，不泄判名）。
- **响应**：输入变化即存 localStorage 并重建榜（逐发签名拼进 `minuteKey`，分钟粒度，不引秒级重排）。

### 2.4 验收（手算 + 开关两态 + 下推）

1. **手算**（2024 上海站，录入 = mock v8 的 17 发：A113 / B 28·35·45 / C231 / D210 / E65 / F40 / G 170·187 / H96 / I88 / J55 / K WA 2:00 + TLE 3:25 / L250 / M30）：拖到 4:32 **定格** → 幽灵 **11 过 / 罚时 1220**（L 题 250′ 在封榜段，显 `250 ?1`；K `205 −2`）；关「封榜视角」**解封** → **12 过 / 1470**（L 显 `250′ + 封榜后`）。真实榜头名只有 8 题 → 幽灵占 **第 1 名**（mock 稿内的邻居只是演示数据，不作验收依据；以实数为准；只录两题时幽灵可落第 258 名，证明也能压在中段）。
2. **开关与清除**：「展示我」关 → 行与读数消失、榜脚/列头/名次全部回到无幽灵状态；开 → 复原；清除（两击）→ 数据没了、入口仍在（可再录）。
3. **占名额下推**：幽灵下方队伍名次下推一位。**样例口径**：4:32 定格 **R#** —— 浙大「又活一天」40→41、北邮「网瘾犯了…」34→35（那是 **R# 列**读数；place 为 31→32 / 27→28）；**掉出金牌带**发生在**终榜**：浙大 place 34→35、金→银（本场金牌带 upTo 34）。

## 3. 不做（本批）

- 「保存 VP」多场存档 / 历史曲线（后话，用户已点名）；预拉取批量 / 整组；幽灵的"打星式"对照开关（改一个布尔的事，先不开）；榜单其它统计口径一律不动。
- 逐发录入是「我的成绩」的数据源（判名五档手输）；不做额外的聚合录入入口。

## 4. 测试与验收

- **单测（纯函数）**：`ghostCell` 逐发折算各态（没录 / 仅失败 / AC / 封榜段 / 未到时刻 / CE / post）+ `buildBoard` 注入（占名额、三排除、封榜带计入、并列 `ti:-1` 在前）+ 存储（sanitize / 历史聚合形状不迁移 / 排序 / 清除 / 键族隔离）+ 预拉取（server 两条返回路径的 `cached`）；手算 11/1220 与 12/1470 有定值用例。**沿用"单测禁真实网络"纪律**。
- **手测**：§2.4 三条 + 目录预拉取三态（含失败态与恢复）+ 顶栏读数跳转与两击清除 + 1280 不折行（顶栏 `.topbar .btn` nowrap 由复核后小修补齐）。
