## 0. 一句话目标

给工作台加第四块 **「模拟榜单」**：从一张收录 **394 场** ICPC/CCPC/省赛/校级/UCUP 的目录里挑一场，用真实榜单数据**按比赛时钟回放**（计时、封榜、暂停/续钟、终局解封、赛后任意时刻回看）——做"跟榜"：你在别处做题，榜单按真实节奏走给你看。同时落地**侧栏收起态**与**导航三处改名**（个人数据 / 工坊 / 模拟榜单）。

## 2. 数据源契约（2026-10-07/08 实测，照抄）

**Base（双源轮转，N1）**：主源 `https://cdn.jsdelivr.net/gh/algoux/srk-collection@master/`；整包已过 jsDelivr 的 50MB 上限（边缘缓存命中仍 200，回源稳定 403），403 时自动切备源 `https://raw.githubusercontent.com/algoux/srk-collection/master/`。两个文件：

| 用途 | 路径 | 实测 |
|---|---|---|
| 目录 | `official/config.yaml` | 48KB，缩进式 YAML 树：`root.children[]` → 五类（`icpc` / `ccpc` / `provincial`（按省分组）/ `university-level` / `ucup`）→ 年份 → 叶子 `{path, format: 'srk.json', name}`；叶子名自带日期（`2025-11-16 沈阳站`）；**共 394 场** |
| 单场榜单 | `official/<path 以 / 连接>.srk.json` | **单场 ~1.5MB**（2025 上海站实测 1,505,682B）；进入回放时加载一次 |

**单场 srk.json 结构（2025 上海站实测解剖）**：

- `type:'general'`、`version`（0.3.9）；`contest{title{zh-CN,fallback}, startAt(ISO+08:00), duration[val,unit], frozenDuration[val,unit]}`——单位有 `ms|s|min|h|d`；**`frozenDuration` 实测常为 `[0,'h']`（= 未声明）→ 按 §4 缺省处理**。
- `problems[]`：13 题，含 `alias`（A–M）/`title`（题名，可给列头 tooltip）/`statistics{accepted,submitted}`（列头"过 N / 交 M"）/`style`（原始题色）——**列序即 `statuses` 的对应序**（防御：长度不齐时缺者按空）。
- `rows[]`：356 队（正式 331 + 打星 25）；`user{name 队名, id 机位号, organization 学校, teamMembers[{name}], official}`；`statuses[i]{result, time, tries, solutions[]}`——**`statuses[].time` 是 `[值, 单位]` 元组（实测秒）；`solutions[].time` 是毫秒**；**`statuses[].result` 实测枚举 = `AC / FB / RJ / null`**（`WA / TLE / RTE / CE` 只出现在 `solutions[]` 里，另可能有冻结占位 `?`）。`solutions` 为**逐次提交**，回放重建的数据基础。
- `series[]` 奖牌规则：如 `{title:'#', segments:[{title:'金奖',style:'gold'},…], rule:{preset:'ICPC', options:{count:{value:[30,60,90]}}}}` + `R#(Normal)` + `S#(UniqByUserField organization, official only)`。
- 奖牌带实测 = **按正式队名次 1–30 金 / 31–60 银 / 61–90 铜**；打星队不挂色带（名次照列）。

### 2.1 缓存与拉取（服务端）

- **目录**：`vault/arena/_catalog.yaml`（原样缓存；`fetchedAt` 取文件 mtime）。命中缓存直接回；`刷新目录` 强制重拉。
- **单场**：`vault/arena/<路径镜像>.srk.json`（如 `vault/arena/official/icpc/icpc2025/icpc2025shanghai.srk.json`），**原子写入**（tmp + rename）。已缓存即回（`fromCache`）；`?refresh=1` 重拉；**历史场次内容终局不变，默认永不过期**。
- **YAML 解析：手写窄解析**（技术锁禁新依赖，不许引 js-yaml）：缩进 2 空格、只认 `path/name/children/format` 四个键、忽略其它行；解析出 `{name, path, children?}` 树 + 每层计数。必须带单测（正常 + 形状异常防御）。
- **路径白名单**：`^official/[a-z0-9_\-]+(/[a-z0-9_\-]+)*\.srk\.json$`（拒绝 `..`、编码绕过、外部域）。
- 超时 = **总预算**（N3）：目录 20s、单场 90s（1.5MB）——重试与退避都从预算内扣，不是单次请求超时；每条源最多重试 3 次、退避 0.5 / 1.5 / 4s，总尝试上限 = 源数 ×（1+3）（N2）。403 / 408 / 429 / 5xx 归**暂时取不到**（可换源重试），404 换源后仍是 404 才判**上游没有**（N4）。失败分两档文案（N11）：`unavailable`（两源死因逐条列 + 重试键）/ `not-found`（明说上游没有，不诱导重试）。**有缓存时上游失败照常回放**（降级不崩）。

### 2.2 API

```
GET /api/arena/catalog              → 200 { fetchedAt, total, tree } ｜ 502（无缓存且拉不通）
GET /api/arena/catalog?refresh=1    → 强制重拉
GET /api/arena/contest?path=<官方路径> → 200 { fetchedAt, fromCache, data: <srk.json 原样> }
                                      400 路径非法 ｜ 404 上游确实没有（`not-found`）｜ 502 暂不可达（`unavailable`）
```

## 3. 落库与持久化

- **不进 `anvil.db`**（无 schema 变更）；全部走 `vault/arena/` 文件缓存。
- **回放会话在 localStorage**（每场一条 `arena:session:<官方路径>`：`{started, hold, paused, ended, scrubMs}`，交付实现另存 `at`（暂停/结束冻结的那一秒）与 `durationMs`（时长封顶））：刷新/离开再回来**按开始时刻续钟**（回来时给「会话已续」提示，稿内行为）；`结束` 清记录落回顾；侧栏收起状态 `arena:rail` 同法持久化；目录另存 `arena:tree`（展开中的组键集合）与 `arena:tree-scroll`（目录滚动位置，搜索态不写）（N13）。

## 4. 回放引擎口径（核心，照 mock 逻辑移植 + 单测）

> 稿内引擎是我们自己的参照实现（非第三方代码），逻辑可整体移植；把它拆成**纯函数模块** `components/arena/engine.ts`。

- **时钟**：`开始模拟` 记 `started=now`；每秒 `elapsed = now - started`（暂停则冻结）；`elapsed ≥ duration` → 自动落回顾。
- **cap（计分截止）**：回放中 = `min(elapsed, 封榜起点)`（**封榜即定格**：名次/过题/罚时都只算封榜前）；回顾 = 按「封榜视角」开关 —— 关（默认）＝ cap 取 `elapsed` 本身（**全量解封**，`buildBoard` 的 `unsealed`）；开 ＝ 同回放定格。elapsed ≥ duration（终局）合并为全量解封。
- **封榜段**：起点 = `duration − frozenDuration`；**`[0,'h']`/缺失 = 未声明 → 缺省最后 60 分钟**。封榜段内的提交：格子显 `?n`（有活动、结果未知）、**不计名次与罚时**。
- **罚时（ICPC）**：`AC 分钟数 + 20 × AC 前失败次数`；**CE 不计失败**；`?` 不参与。**不追上游**（N10）：上游部分文件存原始秒和，与上游 `score.time` 的差异（32 场实测 12.53%，≤4 分钟）按本口径为预期 —— 上游自己两套口径，跟随其一会让引擎不确定。
- **排名**：过题降序、罚时升序；并列同名次、其后跳号（1,2,2,4）。`S#` = 按学校取头队排名的"每校首行"名次（`UniqByUserField organization · 官方队`）。
- **奖牌**：解析 `series[]` 中含 `segments + rule` 的那支（实测 preset `ICPC`，`count.value` 数组；若带 `ratio` 与 `count` 并存取每段 `min(count, ratio×denom)`，`denom ∈ all|scored`）；名次落段即挂金/银/铜色带；**打星不挂带、不占带**；无 `series` 信息 → 不挂带（不猜）。
- **题目格五态**（实现含第六态 **CE**：`solutions` 里存在只含 CE 的格子，单列一档、不罚时；榜脚图例仍按五档）：空 / 罚时中（`-n` + 末次时间）/ AC（时间 + 次数 `×n`）/ **首杀 FB（深绿）** / 封榜 `?n`（斜纹 + 虚线描边；与"空"、"红罚时"三者互斥）。
- **终局解封两态（封榜后通过 / 封榜后未过）**：仅终榜/回顾出现——底色与字色各**退一档** + 右上角一枚圆点；若首杀也在封榜后，小字仍写 `FB`、底色同样退档（不叠深绿）。读法：「这一格发生在封榜段，没有改变定格名次」。
- **提交明细弹层**：逐次 `结果 + 时间`；封榜段内的记录显示 `Frozen`（不泄露结果）。
- **判名优先（N8）**：`statuses[].result` 优先于 `solutions[]` —— 重判撤销场（`result:'RJ'` 而 `solutions` 残留 AC）按被撤销处理，与上游 `score` 对齐。
- **近似榜（N9）**：整场无 `solutions[]` 的老场次按「终局判名 + 次数」重建（格子只在判名那一刻出现）；顶栏挂「近似回放」pill、弹层注明「本场快照没有逐次提交记录」。
- **性能**：solutions 预排序、每秒重建增量计数（榜只在分钟滚过时重建）；行组件 `memo` + 弹层回调 `useCallback`（live 走钟每秒只重渲顶栏计时）；行级 `content-visibility:auto` + `contain-intrinsic-size:auto var(--rowh)`（收放侧栏的列宽补间只重排屏内行）——356 队 × 13 题不许每秒全表重排。

## 5. UI 契约（以 mock-04 为准，逐条对照实现）

### 5.1 赛事目录（s1）

- 头部：`模拟榜单` 标题 + 「目录 394 场 · 榜单来自官方快照」 + `刷新目录`；搜索框（按赛事名过滤，含年份/城市；无结果给空态文案）。
- 树：五类 → 年份（`N 场` 计数）→ 场次行：`日期 + tier 徽章 + 名称 + [开始模拟] [查看终榜]`；tier 徽章照稿（邀请赛/网络赛/区域赛/决赛四款）。**层级视觉（N12）**：每级 14px 递进 + 竖向导轨 + 同级斑马线 + 组头横带与计数 pill；**默认全收起**（N14），展开态与滚动位置持久化（§3 的 `arena:tree*`）。
- 进行中会话：该场行内显 `回放中 · 时刻`（绿点）+ `回到回放`；其余给两个动作。
- 三态：加载（拉目录）/ 失败（CDN 不可达 + 重试）/ 搜索无结果。

### 5.2 回放榜（s2）

- 顶栏：`回到目录` · 比赛名（截断，tooltip 全名 + 开赛时刻 + "封榜 4:00（本场未声明 · 按缺省）"口径） · **计时 `hh:mm:ss`**（绿点=活跃） · `暂停/继续` · `结束` · 封榜中 pill（`剩 x`） · `仅正式队` 复选（默认关）。
- 榜体：`R#`（奖牌色带，左缘由深渐浅）· `S#` · `ORGANIZATION` · `TEAM`（打星 ★）· `SLV` · `PEN` + 13 题列（列头 = 别名 + `过 N`；`交 M` 进 tooltip）；**列宽（v6）**：`46 + 34 + 1fr + 1.12fr + 46 + 56 + 13×36`，行高 36 / 列头 50 / 主读数 12.5 等宽 / 次读数 9.5；**榜体填满内容区**（v6 去掉 1030 收口），余量全归 Org/Team（≈158/177 @1280、≈233/262 @1440）——**1280 不横滚**，靠榜内竖滚 + sticky 列头，超长校名/队名截断、全文走 tooltip。
- **列头五档（N5/N6/N7）**：`quiet` 无人提交 / `pending` 待定（封榜段内有活动、结果未定 —— 不与「交而没过」混档）/ `noone` 交而没过 / `any` 有人过 / `late` 封榜后才解开（判据：该题**所有**过题都在封榜后，`postAc === ac`）；表达 = **整格淡底**（`noone` 淡红 / `any` 淡绿 / `pending` 灰斜纹 / `late` 黄斜纹），色用 warn 家族（暗一档），**不用主色琥珀**；随 cap 实时重算。
- 封榜带：榜头上方一条窄带「封榜中 · 名次定格在 `4:00`」+ 右侧「结果未知 `44` 格 · 涉及 `38` 队」；斜纹只铺在带内。
- 弹层：点队名 → 队名/学校/三名队员/打星标记/机位号；点格子 → 提交明细。
