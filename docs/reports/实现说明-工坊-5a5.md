## 4. 已知问题 / 不处理项

- **P2-3 关联查找复杂度优化**：不在本片（契约 §8）。前端 `allById` 已把每行自建 Map 收口为一份 memo 派生，但仍是 O(n) 构建，不做索引级优化。
- **键盘 / reduced-motion 专项走查未做**：本片未新增交互模式（选择器 / 按钮均为既有组件与禁用态），1280 宽截图正常。
- **归档视图的比赛行「题组 N」只统计归档题组**（本视图口径）；跨视图完整关联在详情里展示。契约 §5.3 未要求行级跨视图计数。
- **旧 problem（被父对象带着归档）详情**显示「只读」但无「取消归档」按钮——它的恢复动作在父比赛上；服务端对它仍允许 API 级编辑（`archived=false` 才是冻结判据），UI 侧已按只读处理。
- 手测时浏览器截图接口两次 30s 超时，均为偶发，重试后成功；与本片代码无关。
