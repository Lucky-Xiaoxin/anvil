> **交付对象：实现 agent（开工提示词另出）**。本文件 = 本批唯一实现契约；**视觉基线 = `design/mock-04-simboard.html` v7**（2026-10-13 修订），对照图 `design/_shots/_shot-v7-*.png`（5 张）。范围仅限 `模拟榜单` 模块。
> 拍板沿革（供背景）：回顾解封争议 → 用户提出「封榜视角」开关（已交付）；本轮用户提出**预拉取**与**幽灵行**；幽灵姿态（打星式 vs 占名额）用户拍**占名额占排名**；「展示我」开关经一致性修订收进面板（否决"有数据才出现的顶栏开关"）；「清除本场成绩」用于二次 VP 从零再来；「保存 VP」是后话不在本轮。

---

## 0. 一句话目标

目录里能把某一场的快照**预拉取**到本地（VP 前备好、断网可回放）；回放榜里能把**你 VP 的成绩**作为一行「我的成绩」按引擎口径插进榜里——随时一眼看到自己排在哪两队之间、在什么奖区。

---

## 1. 预拉取（s1 目录）

**语义**：把单场 `srk.json`（~1.5MB）经服务端拉到 `vault/arena/` 缓存，**不进入回放**。已缓存 → 断网可回放（与 §2.1 缓存的既有降级承诺一致）。

**服务端**：
- `GET /api/arena/catalog` 的每个叶子加 `cached: boolean`（按镜像路径 `existsSync`，394 行零压力）；`ArenaCatalogNode`（shared）加可选字段 `cached?: boolean`。
- 预拉取本身**不新开接口**：前端直接调既有 `GET /api/arena/contest?path=`（命中即秒回；未命中走双源轮换 + 总预算，与回放取数同一路径）。

**前端（行内第三枚动作）**：
- 未缓存：`btn--xs btn--ghost` + sync 图标「预拉取」；点击 → 「拉取中…」（禁用重复点）→ 成功就地变「**本地**」小标（绿点）。失败 → 回到按钮 + 一行提示（复用现有失败口径，不弹大 alert）。
- 已缓存：「本地」小标**替代**按钮；live 行（回放中）不显示（其动作是「回到回放」）。
- 与「开始模拟 / 查看终榜」并列常驻；三枚按钮在 1280 不折行（mock v7 已按 1280 验过）。

**验收**：点击 → 三态过渡 → 刷新目录该行仍「本地」；上游断网时该场仍能从目录进入回放。

## 2. 幽灵行「我的成绩」（s2 / s3 榜体）

### 2.1 存储

- localStorage 每场一条 **`arena:ghost:<官方路径>`**：`{ show: boolean, marks: [{ p: 题序, ac?: 分钟, fails?: 数 }] }`（`ac` 缺省 = 未过；单位 = **比赛分钟**）。坏 JSON / 读不出 → 当没有；读写真一律 try/catch（同 `session.ts` 口径）。
- **清除本场成绩** = 删除该键；直接改数是覆盖，不需先清。幽灵**与 `vault/` 缓存、回放会话互不相干**。

### 2.2 引擎口径（核心，全部与榜单同源）

- buildBoard 增配：`buildBoard(model, elapsed, onlyFormal, unsealed, ghost?)`。幽灵是**合成行**，建议 engine 内单独 `ghostCell(p, elapsed, cap, freezeStart)` 生成格子，**不要伪造 `SrkSolution` 去骗 cellAt**（WA 无时刻可用）。
- 计分（必须与榜单逐字同口径）：`solved = 已过题数`；`pen = Σ(AC 分钟 + 20 × AC 前失败次数)`。**AC 前失败计入罚时（×20）；AC 之后、未过题的失败不计**——这是 ICPC 与全榜口径（讨论中用户口误已当面纠正）。
- `elapsed`/`cap` 跟随现有引擎：live 段内只算 cap 前；回顾「封榜视角」**开** → 段内格回 `?n`；**关（默认解封）** → 直接显结果并带「封榜后」两态（post）。
- **名次与奖牌：占名额版** —— 幽灵走正式队通道：占 `place`、吃奖牌带，其下方队伍的名次与奖牌随之重排一位（mock v7 可见）；`S#` **不给号**（该格空）。
- **排除项**：不计入榜脚「榜上 N 队 / 累计过题 M」、不计入列头「过 N」与列头五档判定；封榜带「结果未知 N 格 · 涉及 N 队」**计入**（你确实有未知格）。打星 FB 不适用（幽灵不抢首杀）。
- 格显示：已过 = `分钟 ×n`（n = AC 前失败 + 1，>1 才显）；未过 = **只显 `−n`**（输入里没有末次时刻）。
- 平局：并列同名次沿用引擎既有 `sameScore` + (last, ti) 裁决，幽灵以其 last AC 参与，不另造规则。

### 2.3 界面（以 mock v7 为准）

- **入口（常驻）**：榜体顶栏（s2 / s3 都有）一枚**图标按钮**（人形 `i-user`，`btn--ghost btn--sm` 尺寸；tooltip「我的成绩 · 录入 VP 成绩，看自己在榜上的位置」）。**不随数据出现/消失**——顶栏长相每场一致（一致性原则；"有数据才出现"的变体已被否决）。
- **面板（浮层，复用 `.pop` 壳）**：标题「我的成绩」；副题「你 VP 时的成绩 · 罚时 = 过题分钟 + 20 × AC 前失败（与榜单同口径）」；**十三行 `A–M` ×（过题′ / 失败）**两个数字输入（留空 = 未过）；底部「**展示我**」开关（默认开；关 = 隐藏行但保留数据）+「**清除本场成绩**」（建议两击确认）；一行小注「留空 = 未过；段内成绩按时间轴与封榜视角自动同口径」。
- **幽灵行（板内）**：左缘 accent 竖条 + 极淡 accent 底（可与奖牌底纹**叠加**）、ORG 列「我的成绩」、TEAM 列「你」（accent 色）；点格 / 点行弹层照常可用（显示合成明细）。
- **响应**：输入变化即存 localStorage 并重建榜（增量重建走现有 minuteKey 口径，不引入秒级重排）。

### 2.4 验收（手算 + 状态对调两件）

1. **手算**：上海站拖到 4:32，输入 mock 同组数（11 过 / 罚时 1220）→ 榜上落在「上海大学 1816」与「武汉大学 1242」之间；251′ 那颗在定格视角显 `?1`、解封视界显结果 + post。按 §2.2 规则手算一遍核对。
2. **开关与清除**：「展示我」关 → 行消失、榜脚/列头/名次全部回到无幽灵状态；开 → 复原；清除 → 数据没了、入口仍在（可再录）。
3. **占名额**：幽灵下方队伍名次下推一位、奖牌带随之重排（对照 mock v7 `_shot-v7-sheet.png`）。
