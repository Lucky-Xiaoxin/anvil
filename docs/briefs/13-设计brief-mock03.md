> 交付对象：前端设计 agent。目标产物：`design/mock-03-xcpc.html`（单文件、零外部依赖、双击预览）+ 截图。
> 前置阅读：`docs/contracts/09-AT规格.md` §9（XCPC 契约，2026-10-05 实测复核版）；`design/mock-02-three-ends.html`（切片 2 视觉基线，冻结）——本稿在其上把 **XCPC 占位屏升级为完整选手档案屏**。
> 口径来源：平台色分档、段位色、文案从简、动效定稿等均已定，见 mock-02 屏 4 与 `docs/reports/11`。

## 0. 一句话目标

把三端 tab 里的 XCPC 从占位升级为**完整选手档案屏**。这条赛道的数据本质与 CF/AT 完全不同——**没有提交粒度、场次稀疏、但有队伍名与奖牌**。本稿的设计核心：**用同一套视觉体系，表达一种"稀疏、庄重、有荣誉感"的数据**，同时一眼可辨"换了个平台"。

## 1. 数据现实（先理解再动手 · 全部为 2026-10-05 实测）

**能拿到什么**（`docs/contracts/09` §9 是完整清单，这里是设计视角的速览）：

| 维度 | 数据 | 说明 |
|---|---|---|
| 身份 | 姓名、学校 | key = `姓名@学校`；重名**不做**复杂处理（候选列表里靠学校区分） |
| 当前分 | officialRating | 全榜（63,120 人）里的 rating；**无段位色名**（不套 CF/AT 段位规则） |
| 名次 | officialRank ÷ 63,120 | 官方榜名次；另有 all 榜（68,940 分母），**本工具只用 official** |
| 奖牌 | 决赛 / 区域赛 / 邀请赛 / 省赛 × 金 / 银 / 铜 | 零奖牌 tier 直接省略；无奖牌者不渲染表格 |
| 逐场（核心） | 日期、比赛名、**队名**、名次÷队数、百分位、过题数、Perf（表现分）、赛后分、tier、罚时比（dirt）、首 A 分钟、最后一小时过题 | 打星场（`official:false`）行照列、成绩列渲染 `—` |
| 生涯 | 参赛场次、最佳名次、生涯跨度（首场~末场） | 最佳名次需前端从逐场算（`min(rankOfficial)`） |

**数据的三条"手感"**（设计必须吃透）：
1. **稀疏**：活跃选手一年 5~10 场，三年 20~30 场（实测样本：用户本人 3 场；一个 27 场的选手已算很活跃）。rating 曲线是**稀疏点**，不是 CF/AT 那种密集折线——**x 轴建议用"场次序号"而不是时间**（时间轴会把点挤在两端、大片空白）；每场悬停再给日期。折不折线/怎么连可发挥。
2. **有队伍**：每场有队名（同一个人不同场常换队名——实测用户 3 场用了 2 个队名：`想成为赛码高手`、`那一天,人类想起了被WA支配的恐惧`）。**这是 CF/AT 没有的字段，也是 ICPC 的灵魂**，值得在战绩表里给一列。
3. **有层级**：每场有 tier（决赛/区域赛/邀请赛/省赛）——名次的可贵程度随层级不同；奖牌也按层级分桶。

**数据是"快照"不是"实时"**：heimaom 是社区定期生成（当前版本 `generatedAt` = 2026-09-28）。"同步" = 下载最新快照。诚实标注要点：① 来源 = xcpcrating 社区数据（非官方）；② 口径 = 官方榜；③ **数据版本日期要露出来**（如脚注"数据版本 2026-09-28"）。

**样本附件**（真实数据，用户已授权用于设计）：
- `李鑫杰@佛山大学`（3 场）：rating 1347.77 / official 1353.13 / officialRank 41867；省赛 166÷298（前 55.7%）过 4 题 Perf 1393.72；ICPC 网预两场 1335÷2535、1725÷2622；奖牌 = 省赛铜 1。
- 奖牌样板：某 27 场选手 = 决赛银 2 / 区域赛银 5 铜 2 / 邀请赛金 1 / 省赛金 3 银 2。
- **本稿演示数据的画像规格**（别只画 3 场，也别画成 CF 密度）：15~25 场 / 跨 3 年 / rating 从 1480 爬向 1950 带起伏 / 奖牌 = 省赛金银若干 + 邀请赛 + 区域赛银 1~2 / 无决赛 / **含 1 场打星行**（验证 `—` 渲染）。名字用虚构的（带真实感即可），页脚照旧"数据为演示假数据"。

## 2. 要设计什么（四屏）

**s1 · XCPC 完整屏（已认领 · 有数据）**
- tab 条沿用 mock-02（新增：XCPC tab 的 rating 数字有值了，颜色按定档平台色）。
- 画面构成建议（可调，欢迎更好的分配）：
  - 一行：**选手卡**（姓名 / 学校 / 当前分 / 全榜名次 ÷ 63,120 / 参赛场次 / 生涯跨度 / 最佳名次——哪个进卡哪个进小字你定）
  - 一行：**rating 轨迹卡**（场次序号轴 + 悬停出比赛详情：比赛名/日期/名次/±分）
  - 一行：**奖牌墙**（按 tier 分行，金/银/铜计数；空 tier 省略；无奖牌给 `—` 而不是空网格）
  - 一行：**逐场战绩表**（全宽；列建议：日期 | 比赛(含 tier 标记) | 队名 | 名次÷队数(含百分位) | 过题 | Perf | 赛后分±；**最新在上**；打星行成绩列 `—`）
  - 脚注：诚实标注（来源/口径/数据版本）
- 没有活跃格子图——这是刻意的（该源没有提交粒度），屏面比例自己重新配平。

**s2 · 未认领空态**
- "还没有认领 XCPC 选手档案" + **就地搜索**（输入姓名或拼音 → 候选 → 确认，一步到位，别只放"去设置"）。

**s3 · 认领交互（细节态）**
- 搜索过程：输入"李"→ 加载 → 候选列表（`李鑫杰@佛山大学` + `3 场`）；**支持拼音**（输入 `lxj` 也能命中）。
- 选中 → 确认块（选中者信息 + "认出我的档案"按钮）→ 认领完成态。
- 已认领后换人：设置页 XCPC 行的同款搜索组件（行内版本）。
- 重名不做特定处理（候选里自行看学校）。

**s4 · 组件与状态**（本屏兼"必答对照"）
- 新组件：tier 标记（决赛/区域赛/邀请赛/省赛 四款）、奖牌计数 chip、战绩表行（含打星行）、选手卡、搜索候选行。
- **平台色对照（必交）**：XCPC 走加强版（卡片极淡色晕 + 同色描边 + tab 指示/卡头 label/读数线）。色相出 **2~3 个候选**同屏对照（建议至少包含：绯系 `--bad` 亮一档、银系 `--silver`；可自行加第三个），把"选中 tab + 一张卡"的局部各画一份——**这是本稿最需要用户拍板的一项**。
- 源状态：缓存过期 / 不可达（沿用降级条与状态点体系）；同步中（顶栏按钮 is-busy）。

## 3. 硬约束（沿用，不得破）

- tokens / 组件 / 动效全部沿用 mock-02（tab 切换编排、reduced-motion、focus 可见、1440×900 基准 + 1280×800 不破版）；**不引入新色系**（除平台色候选）。
- 文案从简：不写解释性注释；口径进 tooltip 或脚注一行。
- XCPC rating **无段位色名**；**official 单口径**（不做两榜切换）；skillPanel 不进本稿。
- 演示数据确定性（静态或种子生成），reduced-motion 直落终值，截图给 `design/_shots/`（命名 `_shot-v4-*.png`）。

## 4. 完成后回复什么

文件路径 + **3 条最需要用户拍板的决策**（其中必须包含平台色相）+ 已知取舍。

## 附 · 在线参考页（2026-10-05 已看实渲染）

**参考**：`https://heimaom.cn/#/player/李鑫杰@佛山大学`（xcpcrating 官方站，与本稿数据同源）。

**借鉴它的「信息组织」**（经该站点长期验证的取舍）：
- 头部 = 大名字 + 学校 +「分卡」（当前分大数字 + 全榜名次）+ 三个指标（正式场次 / 最佳名次 / 生涯跨度）。
- 战绩表列 = 日期 / 比赛 / 队名 / 名次÷队数 / 表现分 / 赛后分——与本 brief §2 的列选择撞车，说明这套列是合理集合（我们另加 tier 标记与过题数，空间自行权衡）。
- 区隔用细线 + 小标签（"奖牌墙" / "表现分轨迹" / "连胜历史"），克制。
- 它的十三维能力面板（雷达 + 轴列表）是**切片 4 掌握图**的好参考，本稿不用。

**不要抄它的**：
- 视觉语言是浅色衬线「档案页」，本工作台是深色仪表盘——XCPC 屏必须融进 mock-02 体系（tab 切换的前提就是"同一个工作台换数据源"，风格漂移会破掉这个感觉）。
- 它的「表现分轨迹」用时间轴画稀疏数据——实渲染下 3 场几乎是一张空白图（反面教材）；本稿用**场次序号轴**解决。
- 口径切换（正式/全部）我们不做（official 单口径）；顶部导航/搜索框也不需要。
