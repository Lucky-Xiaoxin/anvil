## 唯一交付物

`E:\icpc-workspace\design\mock-01-dashboard.html`

- 单文件、零外部依赖（不引 CDN / 外链字体）、无构建、双击即开；
- 顶部用 vanilla JS 做一个简单 Tab 切换，共 4 屏：
  1. **仪表盘（有数据）**——主角屏，见下方规格；
  2. **设置向导**——输入 CF handle → 校验按钮 → 全量同步进度（进度条 + "已拉取 X 条"）→ 完成态；
  3. **空态与未解锁**——无数据引导 + "掌握图 / VP"两个未解锁模块占位；
  4. **组件与 Token 表**——色板、字号、间距、圆角、按钮四态、格子 hover tooltip 演示、动效重播按钮，末尾附 3-5 条设计决策说明。
- 页面底部一行小字：`ANVIL · 视觉稿 v1 · 数据为演示假数据`。

## 风格方向（核心）

关键词：**深色机房 + 铁匠铺的炉火**——精密、安静，有锻打的力量感；游戏化但克制：是"成就系统"，不是"手游大厅"。

- 色板（起点，可微调但气质不变）：

  ```
  --bg:#0A0C10  --panel:#12161D  --panel-2:#171C25  --line:#222A36
  --text:#E8ECF3  --text-dim:#94A0B4
  --accent:#F5A524（炉火琥珀，主角）  --accent-2:#4CC9F0（数据蓝，辅助）
  --ok:#3FB950  --warn:#D29922  --bad:#F85149
  热力色阶（琥珀渐深）：#1A1F29 → #4A3520 → #7A5426 → #B27B2E → #F5A524
  ```

- 数字一律等宽字体 + tabular-nums（Cascadia Code / Consolas 回退链）；界面文字用 Segoe UI / 微软雅黑。
- 圆角 10px；间距按 8 的倍数；桌面优先：按 1440×900 设计，1280×800 不破版，不做移动端。
- 动效 ≤ 200ms ease-out：数字 count-up、格子 stagger 淡入、hover 微光；必须尊重 `prefers-reduced-motion`。
- 禁止：紫渐变 / AI 味玻璃拟态 / 大色块 emoji / 过度发光阴影；图标用内联 SVG 或几何线条。

## 仪表盘屏规格

- 布局：左侧 220px 导航（仪表盘 / 掌握图 / VP / 设置）+ 顶栏（handle、"上次同步 x 分钟前"、"同步"按钮）+ 内容区。
- 内容区：
  a. 一行 4 张统计卡：总过题数 / 近 30 天过题 / 当前 CF rating（副行：最高 rating）/ 连续训练天数（副行"今天还没开张"或"已连续 N 天"）；
  b. 活跃格子图（主体卡）：53 周 × 7 天、日格约 10-11px、月份与星期标签、5 档色阶、hover 出 tooltip（日期 + "过 N 题"）；
  c. rating 迷你曲线卡：30 个点的 SVG 折线、末点高亮 + 当前值；
  d. "未解锁"卡 ×2（掌握图 / VP）：线条锁形图标 + 一句预告文案（例如"把你做过的题铺成一张技能图"）。
- 假数据必须确定性（固定种子或写死）：画像为一名中国大学生选手——总过题 912、近 30 天 27、rating 1400→1683（最高 1731）、连续 12 天；格子图要有真实感："学期中稳定、周末偏多、近两周断 2-3 天"，不要均匀噪点。

## 质量要求

- 1440×900 / 1280×800 不破版、无横向滚动（内容区可纵向滚动）；
- 键盘 focus 可见；正文对比度 ≥ 4.5:1；
- 完成后回复：文件路径 + 预览方法 + **3 条最需要用户拍板的设计决策**。
